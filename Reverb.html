把一首歌
沉进水里

我在本地写的那个 Underwater + Reverb 效果器，搬到网页上来了。 丢一首歌进来，它会在你的浏览器里跑完整条链：闷音滤波 → 大厅混响 → 轻饱和 → 限幅， 然后给你听、给你下载。文件不会离开这台电脑，也没有任何上传请求。

Source 本地处理 · 不上传
把音频拖进来 或点击选择 · mp3 / wav / flac / m4a / ogg

等待一首歌。
Preset UnderEffect + Reverb
Speed 速度1.00×
Cutoff 闷音截止380 Hz
Reverb 混响湿度0.42
Low 低频重量+7 dB

预设只是起点 —— 拖任何一个旋钮都会变成自定义，转换后按当前旋钮值渲染。

它是怎么做的：28 Hz 高通切次声 → 140 Hz +7 dB 保留低频重量 → 650 Hz −3.5 dB 去掉纸箱感 → 主低通（预设值，转角带一点共振）→ 2.6 kHz −8 dB → 5.6 kHz 二级陡降 → 合成大厅混响（RT60 按预设，45 ms 预延迟）→ 慢速 wobble → 轻饱和 → 限幅到 −1 dBFS。
和桌面版的差别：这里是浏览器里的简版，出 WAV、不处理视频、整首限 5 分钟； 要转 mp4、要批量跑一整个文件夹，还是用本地那份 python app.py。
为什么放在这里：这套参数不是拍脑袋调的，是拿十首成品反推出来的（见桌面版的 README）。 代码值得留在看得见的地方。
